🌍 Language Translation Tool

This project is developed as part of the CodeAlpha Artificial Intelligence Internship. It translates text between multiple languages in real time using Google Translator and also provides text-to-speech functionality for the translated text.

✨ Features

- Translate text between multiple languages
- Real-time translation
- User-friendly interface using Streamlit
- Text-to-speech support

🛠️ Technologies Used

- Python
- Streamlit
- Deep Translator
- gTTS

▶️ How to Run

pip install -r requirements.txt
streamlit run app.py
